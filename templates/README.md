# AI Resume Evaluator

An AI-powered resume evaluation system built using NLP and machine learning techniques to analyze resumes and compare them with job descriptions.

## Features
- Resume and job description comparison
- ATS score calculation
- Keyword matching and analysis
- NLP-based resume evaluation
- Resume improvement suggestions

## Technologies Used
- Python
- Flask
- NLP
- Sentence Transformers
- HTML
- CSS
- JavaScript
